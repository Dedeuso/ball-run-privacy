# Privacy Policy — Ball Run **Last updated:** October 9, 2026 ## 1. Introduction Ball Run is a mobile arcade game developed by Ball Run Studio. This Privacy Policy explains how information is handled when you use Ball Run. ## 2. Information Collection The current version of Ball Run is designed to operate without requiring users to create an account or provide personal information directly to the developer. The game stores gameplay information such as your high score and settings locally on your device. ## 3. Advertising and Analytics The current version of Ball Run does not intentionally include third-party advertising or analytics services. If these services are introduced in a future version, this policy will be updated to explain the relevant data practices. ## 4. Data Sharing Ball Run Studio does not sell users' personal information. The current version is not designed to transmit the locally stored gameplay information described above to the developer. ## 5. Children's Privacy Ball Run is not specifically designed to collect personal information from children. If the game's audience or data practices change, this policy will be reviewed and updated as appropriate. ## 6. Data Security and Retention Gameplay information stored locally remains on the user's device and may be removed by clearing the app's data or uninstalling the game. ## 7. Changes to This Policy This Privacy Policy may be updated as Ball Run evolves. The latest version will be available at the public URL where this policy is hosted. ## 8.
